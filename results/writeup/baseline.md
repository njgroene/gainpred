# Baseline: train briefly and look

Generated by `uv run python -m gainpred.writeup`; do not edit by hand. Protocol amendments 20 and 21.

**The main claim is about access and cost, not only agreement.** The baseline trains 200 updates on the teacher's rebuilt training data and reads accuracy on the test problems, which needs their reference answers. Our checks are computed before any training and never look at a right answer. Per round (confirming runs) our checks cost 9% of a full round; the baseline 56%.

Levels, fitted on the learning runs only (starting points 0-1). As run (amendment 20): G = 15, H = 47, D = 51, committed before any confirming probe was fetched. Variant in the baseline's favour (amendment 21, defined after the confirming runs): Z = 1, G = 15, H = 47, D = 51, committed before the confirming runs were scored with it. The variant asks whether a new length changed at all (Z) before testing the gap to the best teacher.
